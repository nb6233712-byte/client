Exhibit B: System Architecture & Schemas

Security boundaries, Firebase schemas, Cloud Functions endpoints, and trust zones

← Operations Triage

1. Cloud Firestore Database Schemas (11 Collections)

/engagements, /documentRequests, /documents, /tax_documents, /tax_returns, /signatures, /messages, /invoices, /updates, /consents, /audit_logs, and /firm_staff. Cross-tenant access strictly blocked via resource.clientUid checks in firestore.rules.

2. Cloud Storage Vault Hierarchy

Client documents stored at clients/{userId}/tax-years/{taxYear}/documents/{documentId} with 25MB ceiling and MIME restriction. Prepared returns stored at clients/{userId}/returns/{returnFileId}, writable exclusively by authorized practitioners.

3. Trusted Cloud Functions Endpoints

Document acceptance/rejection (documentReviewHandler), return publication (publishPreparedReturnHandler), role management (provisionStaffRoleHandler), and payment webhook processing (paymentWebhookHandler) enforce non-bypassable backend validation.
