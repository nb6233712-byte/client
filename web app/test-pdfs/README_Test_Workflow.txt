THE FILE ROOM — SYNTHETIC TEST PDF PACK
Built for testing the Pivot Aide Tax application workflow.

IMPORTANT:
All files in this pack are fictional test data. They are NOT official IRS forms,
valid tax records, legal consent, engagement agreements, e-file authorizations,
invoices, payment confirmations, or filing receipts. Do not submit them for a real return.

SUGGESTED END-TO-END TEST:
1. Create/use a dedicated test client account and a separate firm test account.
2. Sign in as the test client and open Client Portal > Documents.
3. Upload one source PDF, e.g. 01_Test_W2_Source_Record.pdf.
4. Confirm upload success and record the displayed filename/status.
5. Sign out and sign in as the firm user.
6. Open Firm Portal > Documents (or the relevant client record).
7. Confirm the exact same PDF appears under the correct test client.
8. Open/download it; test Accept and Reject if available.
9. Sign back in as the client and confirm the updated status/notification.
10. Refresh both portals and verify the status persists.
11. Repeat with another PDF and test an invalid/oversized file separately.
12. Verify a different client account cannot access the test client's file.

TEST CASES TO RECORD:
- Upload succeeds
- Firm can see correct file and client
- PDF opens/downloads
- Accept/Reject saves
- Client sees latest status
- Status persists after refresh/relogin
- Unauthorized access is blocked
- Error messages are clear for unsupported or oversized uploads

This pack does not prove the application works; it provides sample PDFs to run the tests.
